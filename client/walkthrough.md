# Project Walkthrough: AI Upsell Engine Redesign

## 🌟 The Vision
The goal was to transform a standard landing page into a high-impact, industrial-grade "Experience" that feels like a premium AI infrastructure tool (inspired by `neweb.ai`).

## 🏗 Key Sections

### 1. High-Velocity Hero
- **Headline:** Massive, bold typography signaling authority.
- **Tech Chips:** Immediate communication of sub-10ms latency and autonomous ML.
- **Global Stats:** Validation through billion-dollar capital processing and 99.99% uptime.

### 2. The Features Bento
- **Design:** A dynamic grid replacing traditional lists.
- **Mockups:** Custom-designed UI snapshots for AI Optimization, Creative Generation, and Revenue Insights.
- **Feel:** Data-driven and professional.

### 3. Command Center (Dashboard)
- **Live Feed:** A simulation of the real-time system tracking every dollar of conversion lift.
- **Charts:** High-fidelity Area charts showing revenue trajectories.

### 4. Operational Flow
- **Clarity:** A 4-stage breakdown (Capture → Inference → Offer → Attribution) that demystifies complex AI backend logic.

### 5. Developer-Ready Integrations
- **SDK Preview:** A live code block showcasing ease of integration for engineers.
- **Ecosystem:** Clean, category-based grid for Shopify, WooCommerce, etc.

### 6. Scalability Pricing
- **Conversion focused:** Prominent "Growth" tier with high-contrast styling to drive signups.

## 🌗 Theme Support
The entire site is fully optimized for **Light** and **Dark** modes, maintaining a premium look regardless of user preference.

## 🛠 Tech Stack
- **React + Vite** (Migrated from Next.js for maximum performance)
- **Tailwind CSS**
- **Lucide Icons**
- **Recharts** for data visualization
- **SF Pro** Typography (Apple System Font)
